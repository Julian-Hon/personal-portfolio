# Personal portfolio

A quiet, responsive portfolio built with plain HTML, CSS, and JavaScript.

Open `index.html` directly, or serve the folder with `python -m http.server 8000` and visit `http://localhost:8000`.

Edit `index.html` for your name, introduction, skills, and contact details. The three project entries are explicitly labeled sample concepts; replace their content and the matching descriptions in `script.js` with your own work. Project preview illustrations are CSS, so there are no image assets to manage.

Fonts load from Google Fonts when online, with Georgia and Arial fallbacks. No build step or dependencies are required.
